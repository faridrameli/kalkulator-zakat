Dasar Privasi

Kemas kini terakhir: Oktober 2026

Ringkasan

Kalkulator Zakat tidak mengumpul, menyimpan atau menghantar sebarang data peribadi anda. Semua pengiraan dilakukan sepenuhnya di dalam pelayar anda. Kami tidak mempunyai pelayan backend dan tidak dapat melihat apa yang anda masukkan.

Data Yang Tidak Dikumpul

Kalkulator Zakat tidak mengumpul atau menyimpan:

  • Jumlah pendapatan, simpanan, emas atau aset perniagaan anda
  • Sebarang maklumat kewangan peribadi
  • Alamat IP atau lokasi anda
  • Maklumat peranti anda
  • Sebarang data pengenalan diri

Bagaimana Kalkulator Berfungsi

Kalkulator Zakat adalah aplikasi web statik yang berjalan sepenuhnya di dalam pelayar anda:

  • Semua pengiraan dilakukan secara tempatan dalam pelayar anda
  • Tiada data dihantar ke mana-mana pelayan
  • Data yang anda masukkan tidak disimpan sama sekali (kecuali dalam cache pelayar anda)
  • Apabila anda menutup tab, semua data hilang

Cookies dan Local Storage

Kalkulator Zakat tidak menggunakan cookies atau local storage untuk menyimpan sebarang maklumat peribadi atau kewangan anda.

Perkhidmatan Pihak Ketiga

Laman web ini dihoskan di GitHub Pages. GitHub mungkin mengumpul maklumat log asas (seperti alamat IP) untuk keselamatan dan operasi infrastruktur mereka. Sila rujuk Dasar Privasi GitHub untuk maklumat lanjut.

Keselamatan Data

Oleh kerana kami tidak mengumpul atau menyimpan sebarang data anda, tiada risiko data anda bocor atau dicuri daripada pelayan kami. Semua pengiraan adalah peribadi dan selamat dalam pelayar anda sendiri.

Hak Anda

Oleh kerana kami tidak mengumpul data peribadi, tiada data untuk anda akses, betulkan atau padam. Anda mempunyai kawalan penuh terhadap sebarang data yang anda masukkan ke dalam kalkulator.

Kanak-kanak

Perkhidmatan ini tidak ditujukan kepada kanak-kanak di bawah umur 13 tahun. Kami tidak sengaja mengumpul maklumat daripada kanak-kanak.

Penafian

Kalkulator Zakat menyediakan pengiraan anggaran untuk tujuan maklumat sahaja. Untuk kepastian mengenai kewajipan zakat anda, sila rujuk pusat zakat negeri anda atau ulama yang berkelayakan.
